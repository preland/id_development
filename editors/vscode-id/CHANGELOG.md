# Changelog

## 0.1.0

- Initial release.
- Syntax highlighting (TextMate grammar) for the `id` language: comments,
  keywords, types, builtins, strings, numbers, function names, operators.
- Linting via `idc.py`: errors and warnings shown as editor diagnostics, with
  directory- or file-scope compilation, and on-type / on-save / off modes.
